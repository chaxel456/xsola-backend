# 1. Introduction

XSOLA combines cloud software with embedded hardware to remotely monitor and control solar energy systems.

The hardware continuously communicates with the XSOLA backend through MQTT over Wi-Fi, allowing administrators to:

- Monitor devices
- View telemetry
- Turn power ON/OFF
- Detect faults
- Monitor battery health
- Monitor solar generation
- Track energy usage

Unlike traditional solar installations, XSOLA transforms a standard solar system into a cloud-connected smart energy platform.

# 4. Hardware Components

## ESP32 Development Board

Purpose:

Acts as the brain of the entire hardware system.

Responsibilities:

- Connect to Wi-Fi
- Connect to MQTT
- Receive commands
- Publish telemetry
- Read sensors
- Control relay
- Report status

Recommended Model

ESP32-WROOM-32

Features

- Dual-core CPU
- 520 KB RAM
- Wi-Fi
- Bluetooth
- ADC
- GPIO
- PWM
- SPI
- I2C
- UART

Operating Voltage

```
3.3V
```

---

## Relay Module

Purpose

Controls electrical power to the inverter or output circuit.

Typical Options

- 1 Channel Relay
- 2 Channel Relay
- 4 Channel Relay
- Solid State Relay (SSR)

Control Voltage

```
5V
```

Logic

```
GPIO HIGH → Relay ON

GPIO LOW → Relay OFF
```

---

## Voltage Sensor

Purpose

Measures battery voltage.

Recommended

- ZMPT101B (AC)
- Voltage Divider (DC)

Typical Range

```
0V–100V
```

---

## Current Sensor

Purpose

Measures current flowing through the system.

Recommended

- ACS712
- ACS758
- INA219

Applications

- Power calculation
- Battery charging
- Load monitoring

---

## Temperature Sensor

Purpose

Monitors battery and enclosure temperature.

Recommended

- DS18B20
- DHT22

---

## Battery

Purpose

Stores energy generated by solar panels.

Supported Types

- AGM
- Gel
- Lithium-ion
- LiFePO₄

Example

# 10. Maintenance

Regularly inspect:

- Battery terminals
- Solar panel cleanliness
- Wiring integrity
- Relay operation
- Sensor calibration
- Wi-Fi connectivity
- Firmware version

Suggested Schedule

| Task | Frequency |
|------|-----------|
| Clean Panels | Monthly |
| Check Battery | Monthly |
| Firmware Update | Quarterly |
| Sensor Calibration | Every 6 Months |
| Full Inspection | Yearly |

# 11. Safety Guidelines

- Disconnect power before servicing.
- Use insulated tools.
- Install proper fuses and circuit breakers.
- Ensure adequate ventilation for batteries.
- Keep electronics dry.
- Follow local electrical codes.
- Only qualified personnel should install high-voltage equipment.
